lengto 0.6 - Quick guide
Windows 10/11 x64. One executable, no installation.
https://github.com/IvanPanzera/lengto

START
1. Open or drop a TIFF, PNG, JPEG or PDF. Ctrl+V pastes an image.
2. Press C: enter a known length and its unit, confirm, then click
   the two reference endpoints.
3. Press M and click endpoint pairs. Esc ends the measurement tool.
4. Ctrl+E exports annotated output. TIFF/PDF can include all pages;
   PNG/JPEG save the current page.

CONTROLS
Left-drag: pan. Mouse wheel: zoom. F: fit the page.
Shift at the second endpoint: horizontal or vertical measurement.
Esc, then right-click a measurement to edit its name or segment.
Click to select a measurement; Delete removes it.
Measurements > Settings: display unit and rounding.
Calibrate: change the scale; Segment replaces reference endpoints.
Bottom arrows or Page Up/Page Down: previous/next page.
Click the number in 1 / 18, type a page, Enter to apply; Esc cancels.
Ctrl+O: open. Ctrl+V: paste. Ctrl+S: save. Ctrl+Shift+S: save as.
Ctrl+E: export. Ctrl+W: close. F1: this guide.

MACROS
Script > Start recording: choose absolute or relative coordinates.
Work normally, including an export if you want an output file.
Script > Stop recording saves a .py file.
File > Run script replays it; Python 3.8+ is required only to run macros.
Esc stops a running script; completed operations remain applied.
Absolute repeats pixel positions. Relative suits resized images with
matching framing; it does not align cropped or rotated images.
Keep opened source files available. Pasted images are embedded in macros.
Python examples and batch workflows are on GitHub.

KEEP IN MIND
One uniform calibration applies to all pages. Use a known reference
on the same plane; perspective and scan distortion are not corrected.
Changing calibration updates existing measurements. Settings affect
labels and rounding, not the original coordinates or calculation.
Exports flatten annotations. Keep the original and a macro to reproduce
an editable session. There is no separate project-file format.
PDF input uses 144 dpi. Large images may have reduced previews; exports
use preview resolution. Extra decimals do not improve accuracy.
Save uses a chosen output destination; keep the original separately.

HELP
Check the calibration unit if lengths look wrong. Use a writable output
folder if saving fails. Select a Python interpreter when prompted.
Paste accepts image data or a copied supported file, not plain text.
Use the GitHub button for the quick guide, examples and issue reports.
Component notices are in ? > About.
